## 0.1.0

Initial public release.
- Interactive Gaussian camera, click-to-pivot, roll, dolly zoom and full-screen preview.
- Qwen Image 2.1 Turbo INT8 and Splat Repair integration.
- Masked detail refinement, reference upload/crop and independent reference sampling.
- Target-proportional canvas and conservative default detail strength.
- Camera keyframes, interpolated poses, sequential PNG export and transforms.json.
- Preview release/restore and optional release before single-image repair.
- Portable SHARP environment selection, sanitized workflows and read-only setup checker.
